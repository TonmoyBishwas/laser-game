# fruit_ninja/assets

Drop this game's art and sound here as you make it. Until a file exists, the
game shows a labeled magenta placeholder, so you can build and play first.

Guidelines: see `../GUARDRAILS.md` and `docs/ASSET_GUIDE.md`.

Suggested files (transparent PNGs, ~240×240 export):
- `fruit_apple.png`, `fruit_melon.png`, `fruit_berry.png`, ... (NO green fruit)
- `bomb.png`
- optional: `splat.png`, `background.png`, `slice.ogg`, `bomb.ogg`

Filenames: lowercase_with_underscores. Pick the name in code first, then draw it
to match.

**Reminder: no bright/saturated green anywhere — green is the laser.**
