# thief/assets

Drop art for the thief game here (transparent PNGs). The game currently draws
everything with shapes; add sprites by loading them in `game.py`/`thief.py` and
blitting them centered (see `../DESIGN.md`).

Useful files to make:
- `thief.png` (~120×160 export, shown ~60×80)
- `treasure.png` (~180×140 export, shown ~90×70)
- optional: `wall_tile.png`, `background.png`

Rules: `docs/ASSET_GUIDE.md`. **No bright green — green is the laser.**
